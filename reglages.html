Mettre les nouveaux tarifs en ligne (2 minutes)
  1. Cliquez sur Télécharger le nouveau fichier tarifs.js ci-dessus.
  2. Ouvrez le dépôt GitHub COMITE_34 → bouton Add file → Upload files.
  3. Glissez le fichier tarifs.js téléchargé (il remplace l'ancien).
  4. Cliquez sur Commit changes. Les formulaires utilisent les nouveaux tarifs après 1 à 2 minutes (actualiser la page).
Attention : le fichier doit s'appeler exactement tarifs.js (si votre ordinateur l'a renommé « tarifs (1).js », renommez-le avant de le déposer).
